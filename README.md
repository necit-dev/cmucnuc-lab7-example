# Небольшая информация
Если говорить грубо, программа состоит из 3 файлов - MyModel.java, MyView.java и MyController.java. В Main.java простым образом все это инициализируется и вызывается, из настроек там по сути только название окна.

На что обратить внимание:
1. В pom.xml нужно подключить саму javaFX и простой сборщик maven (теги dependencies и build, там прикол с версией 0.0.8, но это стандарт, просто чувак выкатил альфа-версию, но она настолько стабильная, что ей пользуются до сих пор)
2. Рядом с package в src/main/java необходим файл module-info.java, он нужен, чтобы правильно подключилась библиотека javaFX
3. Проект запускается спокойно в среде IntelliJ IDEA, для этого специальные генераторы проектов не нужны вообще
